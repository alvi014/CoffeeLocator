# ☕ CoffeeLocator - Development Roadmap

Updated Sprint structure for platform scaling and feature deployment.

---

## ✅ Sprint 1: Foundation & Core Auth
- **Status:** Completed 🏁
- **Objectives:** - Initial setup for .NET API and Angular standalone components.
  - Implementation of ASP.NET Core Identity Framework.
  - Base Database schema and migrations.

## ✅ Sprint 2: Premium Auth & Layout
- **Status:** Completed 🏁
- **Objectives:** - UI/UX for Login and Register with "Guild" premium styling.
  - Advanced client-side validations (8+ characters, Uppercase, Password matching).
  - Real-time visual feedback and API error handling.
  - Branch merging and repository cleanup.

---

## 🏗️ Sprint 3: The Admin Hub (Management)
- **Status:** In Progress ⏳
- **Objective:** Enable full administrative control over coffee shop data.
- **Tasks:**
  - [ ] **Admin Dashboard:** Protected route accessible only by users with "Admin" role.
  - [ ] **Coffee Shop CRUD:** Comprehensive forms to Create, Read, Update, and Delete locations.
  - [ ] **Image Management:** Integration with storage services (Cloudinary/Firebase) for shop photos.
  - [ ] **Search & Filters:** Basic dashboard filtering to manage large datasets of shops.

## 🌟 Sprint 4: Social Experience (Interaction)
- **Status:** Pending ⏳
- **Objective:** Empower the "Taster's Voice" through social interaction features.
- **Tasks:**
  - [ ] **Review System:** 5-star rating implementation.
  - [ ] **Comments & Feedback:** Text-based section for user reviews on shop profiles.
  - [ ] **User Profiles:** Basic view showcasing user activity and historical reviews.

## 🏆 Sprint 5: Gamification & DevOps (Final Launch)
- **Status:** Pending ⏳
- **Objective:** User retention and final cloud production deployment.
- **Tasks:**
  - [ ] **Achievements & Badges:** Backend logic for awarding badges (e.g., "First Sip", "Elite Explorer").
  - [ ] **Dockerization:** Dockerfile configuration for API (Backend) and Nginx (Frontend).
  - [ ] **Cloud Deployment:** Final deployment via CI/CD (Vercel/Render/Azure).
